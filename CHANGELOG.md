# Changelog

## 2.0.0 — Initial GitHub release

- Added an independently collapsible **Errands** section inside Blizzard's All Objectives tracker.
- Displays unfinished errands for the character's current zone in the tracker.
- Removed the older detached objective-tracker companion frame.
- Retained the map-based **Zone Errands** editor and zone-entry checklist.
- Kept zone checklists and collapse state in character-specific SavedVariables.
- Continued using Zone Lore-inspired parchment and frame art, with optional Spoken Zones integration.

Earlier experimental versions (`1.x`) were shared as ZIP builds before the repository was created.
